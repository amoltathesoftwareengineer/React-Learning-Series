# React Learning Series

A structured collection of React examples and practical projects demonstrating modern component-based frontend development.

## Overview

The React Learning Series introduces reusable UI components, props, state, hooks, routing, API integration, and frontend application organization through practical examples.

## Key Features

- React fundamentals
- JSX and component composition
- Props and state management
- useState and useEffect
- Forms and validation
- Conditional rendering
- Lists and keys
- React Router
- API integration
- Loading and error states
- Reusable custom hooks
- Mini-projects

## Technology Stack

- React
- JavaScript
- HTML5 and CSS3
- Vite
- React Router
- npm
- Vitest or Jest, depending on the configured test setup

## Installation

```bash
git clone https://github.com/amoltathesoftwareengineer/React-Learning-Series.git
cd React-Learning-Series
npm install
```

## Run Locally

```bash
npm run dev
```

Open the development URL shown in the terminal.

## Learning Workflow

1. Explore a topic.
2. Run the corresponding example.
3. Modify the component.
4. Observe state and rendering changes.
5. Complete a practical exercise.
6. Test the resulting application.
